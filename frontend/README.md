# FinTrack frontend

React single-page application powered by Vite, Tailwind CSS, Recharts, and Lucide React.

## Commands

- `npm install` — install dependencies
- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build

The Vite development server forwards `/api` requests to `http://localhost:8000`. Start the backend before using data-entry features.
